# Shared implementation boundary

Single SvelteKit package. JavaScript. UI owns routes/+page.svelte, app.css, components. Companion owns extension/, src/lib/bridge/, scripts/build-companion.mjs and tests/adapter.test.js plus static/fixture.html. Integration owner owns package files, domain, storage, import, OCR, docs.

Profile fields are strings and named name, passportNo, birthDate, nationality, birthPlace, sex, passportExpiry, email, phoneCountry, phone. IDs/revision/reviewedAt/updatedAt are metadata. Trip strings are arrival, departure, transportNo, travelMode, embarkation, accommodationKind, address1, address2, state, city, postcode. Dates are ISO YYYY-MM-DD. Import uses these exact headers. Official option catalog is src/lib/official-options.json and schema.js exports it. src/lib/malaysia-cities.json maps official city labels and codes by state. UI uses dependent selects; adapter validates against loaded live options, never guesses.

src/lib/domain/schema.js exports options, cities, PROFILE_FIELDS, TRIP_FIELDS, emptyProfile(), emptyTrip(), STATES, stateLabels, OFFICIAL_URL, CHECK_URL.
src/lib/domain/validate.js will export validateProfile(profile, now = new Date()) => string[], validateTrip(trip, now) => string[], malaysiaToday(now) => ISO date, arrivalRange(now) => {min,max}, fingerprint(profile,trip) => string. Validation messages Indonesian.
src/lib/domain/state.js will export reduceAttempt(submission, event) => new submission with events/state/submittedAt/confirmedAt. Events have id, attemptId (=submission.id), type, at, detail?, reference?. type is filling, awaiting_verification, click_intent, outcome_unknown, blocked, cancelled, reconcile. reconcile requires nonempty reference and marks user-confirmed; click_intent sets submitting and submittedAt. Unknown blocks queue.
src/lib/storage/repository.js exports createRepository(name?) => async methods listProfiles(), saveProfile(profile), deleteProfile(id), listSubmissions(), queue(profiles,trip), appendEvent(id,event), deleteSubmission(id), exportBackup(), restoreBackup(object), clearAll(). All mutation returns saved record except queue returns array, restore returns {profiles,submissions}. saveProfile permits partial drafts; reviewedAt supplied by user after review. queue validates complete/reviewed profiles and trip, enforces unique nationality/passport/arrival fingerprint. Submitted snapshots never mutate. appendEvent is idempotent by event ID.
src/lib/import/parse.js exports parseImport(file, mapping?) => Promise<{headers:string[], rows:Array<{row:number,profile:object,issues:string[]}>, warnings:string[]}>, CSV_TEMPLATE string, MAX_FILE_BYTES, MAX_ROWS. Mapping is object from canonical profile field to input header. No records save until UI review.
src/lib/import/ocr.js exports readPassport(file, onProgress?) => Promise<{profile:object, issues:string[], text:string, confidence:number}>. OCR runs local assets only. MRZ checksum warnings retain draft for corrections.
src/lib/bridge/client.js should export createBridge({onStatus,onEvent}) => {connect(),start(submission),cancel(attemptId),ack(eventId),disconnect()}, downloadCompanion() => Promise<void>. onEvent(event) is awaited before ack. status is {connected:boolean,message:string,activeAttemptId?:string}. App queue starts one record through bridge.start. Events carry attemptId. Do not automatically start next if any unknown. User explicitly runs queue and each manual retry. Could UI use exports matching these; report deviations before commit.
